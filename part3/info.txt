Parte 3
Programando un servidor con NodeJS y Express

Inicio: 01/01/2025
Cierre: 


Comandos
npm init // Inicializar package.json
node index.js // Ejecutar archivo JS
npm install express // Instalar Express
npm install --save-dev nodemon // Instalar Nodemon como dependencia de desarrollo
Ctrl + C // Apagar servidor en la consola

Herramientas
- Uso de Postman para probar la API
- Uso de REST Client de VS Code para las request
